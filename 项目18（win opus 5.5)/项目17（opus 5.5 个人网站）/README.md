# 桃源境 · 一处可以漫游的数字小院

风起桃源，即刻启程。以明亮幻想山谷、卡通光照和游戏 HUD 为视觉方向，基于 Next.js、React Three Fiber 和 Three.js 的个人网站，保留五个内容分区，提供三维漫游和手记列表两种浏览方式。

## 本地启动

推荐 Node.js 24 LTS（最低 22.18）及 npm。

```bash
npm install
npm run dev
```

- 网站：<http://127.0.0.1:3000>
- 内容管理：<http://127.0.0.1:3000/admin>

启动脚本直接使用 Node 调用 CLI，兼容从 Windows 拷贝到 macOS 后 `.bin` 文件缺少执行权限的情况。Windows PowerShell 如果限制 npm 脚本，可以用 `npm.cmd run dev`。

## 把示例换成自己的内容

首次运行展示 `src/lib/data/seed.ts` 中的 12 条示例内容，前台标记「示例小院」。

1. 打开内容管理，逐条修改示例，或点击「写一页」。
2. 勾选「发布到小院」后保存，内容会公开；取消勾选后保存为草稿。
3. 「个人资料」修改名字、简介、身份、位置，以及选填的邮箱和个人主页。
4. 完整的自我介绍在「关于我」内容里编辑。
5. 替换完成后，在个人资料中关闭「示例小院」标记。

发布后重新聚焦网站窗口会刷新内容，也可以手动刷新页面。

## 数据与备份

无需数据库或外部账号即可使用。首次修改时自动创建：

```text
data/
  content.json        # 个人资料、正文、发布状态
  uploads/            # 上传的封面（PNG / JPEG / WebP，最多 3 MB）
  backups/            # 每次修改前的完整内容 JSON
```

可用 `REALM_DATA_DIR` 配置持久化目录。目录必须可写。运行数据、环境变量不进入 Git。

后台「导出备份」导出内容和个人资料 JSON；「从备份恢复」验证数据后整体替换，修改前仍会自动留备份。也可以从 `data/backups` 选择 JSON 恢复。**JSON 中只包含图片 URL，不包含图片文件；迁移时请一起复制整个 `data` 目录。**

浏览器中的自动暂存仅用于正文编辑，不代替服务器保存。个人资料修改需点击保存。

当前存储方案面向单实例 Node.js 服务。多实例、无持久磁盘或纯静态托管需要改用共享数据库与对象存储；旧版 Supabase 模拟逻辑已移除。

## 生产运行

复制 `.env.example` 为 `.env.local`，设置自己的 `ADMIN_PASSWORD`（至少 12 位）。密码不写入源码。更换密码会使原有管理会话失效。

```bash
npm run build
npm start
```

- 默认只监听 `127.0.0.1`，可用反向代理对外提供 HTTPS。
- 生产模式即使从 localhost 打开也必须登录；未设置有效密码时禁止管理写入。
- 仅开发模式且访问 localhost / 127.0.0.1，未设密码时允许直接管理。
- 管理会话最长 12 小时。来源校验要求反向代理保留正确的 `Host` 请求头。
- 上传文件只接受 PNG / JPEG / WebP 文件签名，并通过独立图片接口提供。
- 不依赖远程字体、图片或音频即可运行；示例插图和场景均由代码绘制，环境音在浏览器内生成。

此版本已完成本地开发与生产构建验证，尚未部署到公网。

## 检查

```bash
npm test
npm run typecheck
npm run build
npm run test:integration
```

`test:integration` 需先 build。它启动独立的生产服务，使用随机密码与临时目录，验证认证、来源保护、草稿隔离、增删改、上传、资料、导入、备份和退出，完成后清理临时数据。
