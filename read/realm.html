把个人网站，做成一处可以漫游的风景。

# 交互设计# Three.js# Next.js

为自己造一座桃花源

个人网站不一定是一张履历。它也可以是一片风景，让作品成为林间的灯，让文字藏进竹影，让生活沿着水面慢慢展开。

交互设计

  1. 从一扇门开始，跟随镜头走进山水。
  2. 用五个地点组织不同的内容。
  3. 点击风景中的节点，打开一页故事。
  4. 用「手记」模式快速查找和阅读。

技术实现

使用 React Three Fiber 绘制场景，GSAP 编排镜头，Next.js 提供内容读写。桃林采用实例化渲染，弱设备可以切换为轻量模式。

const idea = '让信息成为风景';
const realm = createSomething(idea);
